# Контракты

Здесь живут все `.proto`: межсервисные gRPC-методы и схемы событий Kafka.

Правила:

- контракт меняется **до** реализации, отдельным PR, с апрувом ментора;
- `buf breaking` в CI сравнивает с `develop` — сломать чужой контракт молча
  не получится;
- сгенерированный код лежит в `proto/gen` и собирается командой `task gen`.

```
proto/
  identity/v1/
  catalog/v1/
  cart/v1/
  payment/v1/
  order/v1/
  events/v1/     схемы событий Kafka
```
